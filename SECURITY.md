# Security policy

## Reporting a vulnerability

Do not post tokens, private attendance links, personal information, or other secrets in a public issue. For a security concern, contact the repository owner privately through the contact method listed on their GitHub profile.

## Secret handling

- Keep Slack bot tokens and member IDs in Google Apps Script Script Properties.
- Do not commit real timetables, private URLs, calendar exports, or screenshots containing personal data.
- If a Slack token is exposed, revoke it in Slack and issue a replacement immediately.
